Command-line utility for inspecting MoPaQ (MPQ) archives and extracting
their members.

## Overview

MPQ is a proprietary archive format created by Mike O'Brien in 1996 for
Diablo. Blizzard also used it in Diablo II, StarCraft, Warcraft II:
Battle.net Edition, Warcraft III, and World of Warcraft.

* `mpq info` reports archive version, offset, member count, packed and
  unpacked sizes, and compression ratio. It accepts multiple archive paths.
* `mpq list` lists members of one archive at a time.
* `mpq extract` writes selected members under generated names
  such as `file000000.xxx`.

## Requirements

On Linux, use a C compiler, GNU make, pkg-config, and a compatible
[libmpq](https://github.com/mbroemme/libmpq) development installation. A Git
checkout also requires GNU Autoconf and Automake.

Use libmpq 0.9.0 or later. The build uses pkg-config to find the development
installation. Until the official 0.9.0 release is available, CI uses libmpq
development commit `b74d9bd598ccfb2108ad5430f12724e421d6e9cf`. The pin will
switch to the official release during release qualification.

## Building and installation

If you installed libmpq in a private prefix, add its pkg-config directory
to `PKG_CONFIG_PATH` and make its shared library available to the runtime
loader.

From the mpq-tools source directory:

```sh
sh autogen.sh
./configure --prefix="${HOME}/.local"
make
make install
```

Source distributions generated by `make dist` already include `configure`.
Start at `./configure` when building from one of those archives.
`make install` installs `mpq` and its manual page. Add
`${HOME}/.local/bin` to `PATH` if you use the prefix above. Run
`./configure --help` for installation directory options.

## Usage

```text
mpq [GLOBAL OPTIONS] info [--] ARCHIVE [ARCHIVE ...]
mpq [GLOBAL OPTIONS] list [-i INDEX ...] [--] ARCHIVE
mpq [GLOBAL OPTIONS] extract [-i INDEX ...] [--] ARCHIVE
```

Use `mpq -h` or `mpq --help` for global help, `mpq -v` or `mpq --version`
for version information, and `mpq COMMAND --help` (or `-h`) for command
help. Place global options before the command and command options before
the first archive operand. Use `--` in the command scope before a path
beginning with a hyphen.

For `list` and `extract`, use `-i INDEX`, `--index INDEX`, or
`--index=INDEX` to select a zero-based member index. Repeat the option to
process indexes in the given order, including duplicates. Omit indexes to
process all members.

Use `-q` or `--quiet` to suppress successful extraction notices, or
`--verbose` for operation and selection details on stderr. Exit status is
0 for success, 1 for operation failure, and 2 for invalid usage.

Extraction writes each member to a temporary file in the current
directory and publishes it after that member completes. Publication
replaces an existing file with the same generated name. Use a fresh output
directory for each archive.

### Examples

```sh
mpq info first.mpq second.mpq
mpq list first.mpq
mpq list -i 0 --index=2 first.mpq

mkdir extracted
cd extracted
mpq extract -i 0 -i 2 ../first.mpq
```

The last command extracts the first and third members as
`file000000.xxx` and `file000002.xxx`.

### Migrating from the legacy commands

| Previous command | Unified command |
| --- | --- |
| `mpq-info archive.mpq` | `mpq info archive.mpq` |
| `mpq-extract --list archive.mpq` | `mpq list archive.mpq` |
| `mpq-extract --extract archive.mpq 1 3` | `mpq extract -i 0 -i 2 archive.mpq` |

## Known limitations

The utility provides read-only archive operations. The extractor uses
generated names and requires numeric member selection for individual
files. Archive and compression support is limited to what the linked
libmpq can read. Ordinary extraction streams each member in a single pass.
It uses libmpq's applicable sector checks and does not perform a separate
whole-member CRC32 or MD5 verification pass.

## Documentation

Use `man mpq` for the installed manual. See [`mpq(1)`](docs/man1/mpq.1)
for the source.

## Reporting bugs

Report problems through [GitHub Issues](https://github.com/mbroemme/mpq-tools/issues).
Include the command, both version numbers shown by `--version`, and the
output you observed. Provide a minimal reproducible example when possible
and avoid uploading copyrighted game archives. Testing against existing
archives and reporting reproducible failures helps the project.
