Command-line utilities for inspecting MoPaQ (MPQ) archives and extracting
their members.

## Overview

MPQ is a proprietary archive format created by Mike O'Brien in 1996 for
Diablo. Blizzard also used it in Diablo II, StarCraft, Warcraft II:
Battle.net Edition, Warcraft III, and World of Warcraft.

* `mpq-info` reports archive version, offset, member count, packed and
  unpacked sizes, and compression ratio. It accepts multiple archive paths.
* `mpq-extract` lists or extracts members of one archive at a time. It
  selects members by number and writes extracted files under generated names
  such as `file000000.xxx`.

## Requirements

On Linux, use a C compiler, GNU make, pkg-config, and a compatible
[libmpq](https://github.com/mbroemme/libmpq) development installation. A Git
checkout also requires GNU Autoconf and Automake.

The build checks for libmpq 0.4.2 or later through pkg-config. It requires
the historical ABI used by this checkout. The CI build uses
[libmpq commit `60c1e1a`](https://github.com/mbroemme/libmpq/commit/60c1e1a35dfca47b03768b00248166eb4849647f),
which reports version 0.4.2 and exports the required size functions. The
version check alone does not establish compatibility.

## Building and installation

### Preparing the historical dependency

If you do not already have the compatible libmpq development files, build
the pinned revision on 64-bit Linux from a directory beside mpq-tools.
Building this dependency also requires Git, GNU Libtool, and the zlib and
bzip2 development headers and libraries. On Debian, the build packages are
`build-essential`, `git`, `autoconf`, `automake`, `libtool`, `pkg-config`,
`zlib1g-dev`, and `libbz2-dev`.

```sh
git clone https://github.com/mbroemme/libmpq.git libmpq-historical
cd libmpq-historical
git checkout --detach 60c1e1a35dfca47b03768b00248166eb4849647f

libmpq_prefix="$HOME/.local/libmpq-mpq-tools"
sh -e autogen.sh
./configure --prefix="$libmpq_prefix" --disable-static --disable-largefile
make -C libmpq
make -C libmpq install
install -Dm644 libmpq.pc "$libmpq_prefix/lib/pkgconfig/libmpq.pc"
```

The historical large-file probe can emit an empty `_FILE_OFFSET_BITS`
definition with modern Autoconf. The dependency build uses
`--disable-largefile` on 64-bit Linux, where `off_t` is already 64 bits.

Run the following in the shell where you will build and use mpq-tools if
you installed libmpq in the private prefix above:

```sh
libmpq_prefix="$HOME/.local/libmpq-mpq-tools"
export PKG_CONFIG_PATH="$libmpq_prefix/lib/pkgconfig${PKG_CONFIG_PATH:+:$PKG_CONFIG_PATH}"
export LD_LIBRARY_PATH="$libmpq_prefix/lib${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
```

### Building mpq-tools

From the mpq-tools source directory:

```sh
sh -e autogen.sh
./configure --prefix="$HOME/.local"
make
make install
```

Source distributions generated by `make dist` already include `configure`.
Start at `./configure` when building from one of those archives.
`make install` installs both executables and their manual pages. Add
`$HOME/.local/bin` to `PATH` if you use the prefix above. Run
`./configure --help` for installation directory options.

## Usage

```text
mpq-info [OPTION] ARCHIVE [ARCHIVE ...]
mpq-extract --list ARCHIVE [NUMBER ...]
mpq-extract --extract ARCHIVE [NUMBER ...]
```

Both utilities accept `-h` or `--help` and `-v` or `--version`.
`mpq-extract` also accepts `-l` for `--list` and `-e` for `--extract`.

Omit the member numbers to list or extract all members. Command-line
member numbers start at 1, while displayed member indexes and generated
filenames start at 0. Extraction writes to the current directory and
overwrites files that match the generated names. Use a fresh output
directory for each archive.

### Examples

```sh
mpq-info first.mpq second.mpq
mpq-extract --list first.mpq
mpq-extract --list first.mpq 1 3

mkdir extracted
cd extracted
mpq-extract --extract ../first.mpq 1 3
```

The last command extracts the first and third members as
`file000000.xxx` and `file000002.xxx`.

## Known limitations

The utilities provide read-only archive operations. The extractor uses
generated names and requires numeric member selection for individual
files. Archive and compression support is limited to what the linked
historical libmpq can read.

## Documentation

The installed manuals are available through `man mpq-info` and
`man mpq-extract`. The source files are
[`mpq-info(1)`](doc/man1/mpq-info.1) and
[`mpq-extract(1)`](doc/man1/mpq-extract.1).

## Reporting bugs

Report problems through [GitHub Issues](https://github.com/mbroemme/mpq-tools/issues).
Include the command, both version numbers shown by `--version`, and the
output you observed. Provide a minimal reproducible example when possible
and avoid uploading copyrighted game archives. Testing against existing
archives and reporting reproducible failures helps the project.
